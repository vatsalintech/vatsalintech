## 🚀 Featured Projects

### 🩺 DataDoctor — Dataset Health Analyzer - [Link](https://datadoctorai.streamlit.app/)

**Making machine learning more reliable, one dataset at a time.**

An interactive data quality analysis application designed to identify dataset problems before model training and demonstrate how preprocessing decisions affect downstream machine learning performance.

**Key Features:**
- Automated dataset profiling and quality diagnostics.
- Detection of missing values, duplicates, outliers, class imbalance, suspicious labels, and potential data leakage.
- Actionable preprocessing recommendations with user-controlled fixes.
- Original dataset preservation through a separate working copy.
- Logistic Regression model training and performance evaluation.
- Training history to compare model performance across preprocessing experiments.

**Tech Stack:** Python · Pandas · NumPy · Scikit-learn · Streamlit
